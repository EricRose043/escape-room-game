棉花糖工坊：閉館之後 — 本機手把試玩

需要 Python 3。雙擊 Play-EscapeRoom.cmd，會啟動本機伺服器並開啟瀏覽器。
固定網址：http://127.0.0.1:8778/index.html
存檔保存在該瀏覽器、該網址；之後繼續遊戲請使用同一瀏覽器與網址。
three.js 引擎已隨附，啟動後不需連網，不需要 npm install。
請完整解壓ZIP後執行啟動器，不要直接雙擊index.html，也不要在ZIP預覽內執行。
127.0.0.1是各台電腦自己的網址，不是可傳給同學連入你電腦的公開遊戲網址。
2026-11-05：開場略過獨立執行；載入失敗會顯示原因，可展開「錯誤資訊」回報。
新版啟動器會更新整套程式版本、禁止舊快取，並核對伺服器的資料夾與版本。
若8778已被另一份本遊戲占用，新版會確認後自動接替，並使用這次點選的資料夾。
其他服務或無法驗證的程序不會被停止，會說明原因；不會自動換網址或刪除存檔。

1. 先用 USB 接上手把（也可使用已配對的藍牙）。
2. Chrome 開啟遊戲後，點一下頁面讓它取得焦點。
3. 按手把任一鍵並放開，讓瀏覽器辨識，再按 A（Xbox）／✕（PS）操作。
4. 先看劇情或略過，再用十字鍵選「重新開始」、A／✕確認。
   若出現確認畫面，選「確認重新開始」。已有存檔可選「繼續」。

左搖桿：移動
右搖桿：轉頭
A／✕：開始、撿物、互動、進櫃／出櫃、選單確認
B／○：選單返回
RB／R1：手電筒開關（拿到手電筒後）
LB／L1：一般光／紫外光切換
Start／Options：暫停／繼續
Y／△：設定
View／Share：地圖（取得地圖後）
十字鍵：選單與密碼鎖選擇

遊戲只接受瀏覽器 standard mapping 手把。
若沒反應：點回頁面、按一下手把按鍵；再試 USB 重新連接。
拔除手把或切換視窗會暫停，接回後需主動按繼續。
近景驚嚇依最新要求預設開啟；新版首次會同步舊設定。之後仍可在設定自行關閉並保存選擇。
Start／Options暫停後，可查看真正的Xbox／PS手把配置圖；遊戲內左右搖桿使用圓盤圖示。
裝配線一旦被娃娃看見就必定抓到，只能提前避開視線或躲櫃。抓捕2.1秒後回存檔點。
新版近景有突進、張顎與雙手收攏；O／Y／△設定的「驚嚇近景」會明示演出是否開啟。
月台改為兩組完整軌道（共四根鋼軌），並標示01／02，發車碼仍為2123。
貨運門與追逐前第一道隔離門：整片門板都能觸發原本門邊的操作，使用E／A／✕。
兩張出口密碼文件：互動範圍已對齊紙張，直接瞄準文字讀取，不需瞄下方牆面。
