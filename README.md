# 密室逃脫遊戲

第一人稱 3D 恐怖密室逃脫，場景是原創的「星星糖果樂園」。目前已實作 STEP 3：移動、碰撞、互動與背包，以及一般光／紫外光手電筒、電量、電池與隱藏字。自動測試 77/77 通過；STEP 3 瀏覽器未驗，由監督者驗收。尚未實作正式關卡或謎題。

## 開啟遊戲（三位組員都適用）

使用支援 importmap、ES module 與 WebGL 的桌面版 Chrome、Edge 或 Firefox。遊戲是靜態網站，three.js 固定使用 `0.160.0`，由 jsDelivr CDN 載入，因此開啟時需要網路。**不用先執行 `npm install`，沒有 npm 套件依賴。**

請先確認電腦有 Python 3；以下指令使用電腦上的 Python，不會安裝任何專案套件。若指令找不到，先安裝 Python 3，再重新開啟終端機。

### Mac

1. 開啟「終端機」，輸入 `cd `（後面有一個空格），將專案資料夾拖進終端機，再按 Enter。
2. 確認所在資料夾看得到 `index.html`，執行：

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. 保持終端機開著，用瀏覽器前往 `http://127.0.0.1:8000/index.html`。

### Windows

1. 在檔案總管開啟專案資料夾，於網址列輸入 `powershell` 並按 Enter，終端機就會開在該資料夾。
2. 執行：

   ```powershell
   py -m http.server 8000 --bind 127.0.0.1
   ```

3. 保持終端機開著，用瀏覽器前往 `http://127.0.0.1:8000/index.html`。若只有 `python` 指令可用，可將上面的 `py` 換成 `python`，需為 Python 3。

兩種系統都按 `Ctrl+C` 停止本機伺服器。若 8000 埠已被使用，把指令和網址中的 `8000` 都改成 `8001`。

**直接點兩下 index.html 會打不開，原因是瀏覽器不讓本機檔案載入模組。** 請使用上述 `http://` 網址，避免使用 `file://`。本機伺服器只負責提供靜態檔案，沒有遊戲後端或帳號服務。

## 執行測試

安裝 Node.js 20 以上版本（包含 npm），在專案資料夾執行：

```sh
npm test
```

不需 `npm install`。這個指令使用 Node 內建的 `node --test`，執行全部測試。STEP 0 會確認 logic 在沒有瀏覽器的 Node 中能獨立載入，並遞迴掃描 `src/logic/` 的所有 `.js`，禁止匯入 three（包含 CDN、動態匯入與轉匯出）。

## 程式怎麼分

- `src/logic/`：純 JavaScript 遊戲規則；不使用 three.js、DOM、`window` 或 `document`，以一般物件和數值交換狀態。目前包含移動、碰撞、視角限制、暫停狀態、物品射線選取、背包、手電筒電量與模式、隱藏字可見性及共用關卡／物品資料。
- `src/game/`：three.js 畫面，之後處理輸入與聲音，將 logic 狀態畫出來。
- `tests/`：Node 測試與 logic 邊界檢查。

## 畫面驗收與效能

開啟後應看到偏暗但可辨識的房間，有地板、四面牆、天花板、燈光與桌子；相機在房內。點房間畫面或按「開始」鎖定滑鼠後，用 WASD 走路、滑鼠轉頭。玩家不能穿過牆或桌子，仰俯角限制為 ±85°。

按 Esc 解鎖滑鼠並暫停；按暫停畫面的「繼續（鍵盤滑鼠）」才會重新鎖定。若瀏覽器短暫拒絕鎖定，畫面會提示「請再點一次」，稍等後再按「繼續」。切到其他視窗或背景分頁也會暫停。調整視窗大小時，畫面比例應跟著更新；可開啟瀏覽器開發者工具的 Console 確認沒有錯誤。

左上角 FPS 約每秒更新一次。量測時保持分頁在前景，等待數秒再讀值。現在採簡單幾何形狀、像素比上限 1、無即時陰影與後製，降低內顯負擔。**30 fps 尚未在舊電腦驗證**；之後各批次結尾需在學校舊電腦全螢幕實測。

## 手把操作

先讓網頁位於前景並取得視窗焦點，接上手把後按任一鍵讓瀏覽器偵測，再按 Xbox 的 A 或 PS 的 ✕ 開始。左搖桿走路、右搖桿轉頭；Start／Options 暫停，再按一次繼續。長按不會反覆切換。只用手把即可開始與繼續，無須點擊或鎖定滑鼠。

只支援瀏覽器回報 `mapping === "standard"` 的手把；未知品牌的標準映射手把可以操作，按鍵名稱採 Xbox 的 A／B／RB。非標準映射會顯示不支援提示並忽略輸入，可改用手把的標準模式或鍵盤滑鼠。瀏覽器未提供 Gamepad API 或拒絕存取時也會顯示提示。

左、右搖桿各有 0.18 的徑向死區，超過後重新映射並套用 1.5 次方曲線。放開搖桿時輕微雜訊不算輸入。鍵盤與左搖桿同時輸入會相加後限制長度為 1，移動不會加速；滑鼠角度位移與右搖桿角速度分開計算後相加。

左下角提示跟隨最後有意義的輸入，但每次切換後至少停留 0.5 秒，避免同時輸入時閃爍。提示種類不會關掉另一個來源的動作。從手把轉用滑鼠時，移動滑鼠可切換提示；若滑鼠尚未鎖定，點一下房間畫面以啟用轉頭。已經鎖定滑鼠時，仍可同時使用手把。用 Start／Options 繼續時會解除滑鼠鎖定，以便純手把操作。

只有提示所對應的目前手把被拔除時才自動暫停；提示為鍵鼠，或拔除另一支手把時，不會因此暫停。重新接上不會自動繼續，需再按 Start／Options。

## STEP 2 互動驗收

遊戲進行中畫面中央顯示準星；瞄準可撿物品時，準星下方才出現「E／A／✕ 撿起」與名稱。按鍵名稱沿用最後使用裝置與 0.5 秒切換保護。E、Xbox A、PS ✕ 的效果相同，長按不連續撿取；開始／繼續當幀不會順便撿物，暫停或失焦不保留待執行互動。

距離從玩家眼睛量到中央射線首次命中的物品表面，恰好 2 m 可撿、超過不可撿。射線碰到較近或同距離的牆、桌子、隔板、地板或天花板時不能撿。多個物品重疊時選最近的未撿物品。每個物品三邊至少 0.25 m，模型與判定共用相同 AABB。撿起後記入 logic 的 `{ itemIds: [] }`，場景模型移除；本步沒有背包選單與存檔，重新整理會重置示範物品。

## STEP 3 手電筒

| 動作 | 鍵盤 | Xbox | PS |
|---|---|---|---|
| 開關手電筒 | F | RB | R1 |
| 一般光／紫外光 | R | LB | L1 |
| 撿電池 | E | A | ✕ |

按下邊緣才觸發，長按不連續切換；提示沿用最後使用裝置與 0.5 秒切換保護。開始／繼續當幀忽略裝備動作與耗電，暫停、失焦不耗電，也不保留待處理按鍵。

起始即有手電筒，100% 電量、關閉、一般光。開啟時每秒減少 0.2 個百分點，兩種模式相同；滿電可連續使用 8 分 20 秒。電量 0 自動關閉且無法開啟。關閉時可切換模式；補電不會自動開燈。STEP 4 再加入先撿到手電筒的關卡限制。

起點正前方及左前方桌上的兩顆電池沿用 STEP 2 撿取：距離、瞄準、遮擋、場景移除與背包規則皆相同。每顆補 25 個百分點，最多 100%；滿電仍可撿，溢出捨棄。補電只對新取得的 ID 執行一次。這是初始平衡值，正式章節的電池配置與難度需在關卡完成後實玩調整。

隔板背面有示範隱藏字「星光在此」，位置 (2.5, 1.6, -0.02)，朝向 -Z。從隔板兩側繞到北側（例如玩家 X=2.5、Z=-2），回頭朝 +Z 照射。只有有電、開啟紫外光、文字中心在半角 25° 與 8 m 範圍內（含邊界）、玩家位於正面且中間無方塊遮擋時，整段文字才顯示。文字位置與法向量只定義於 `src/logic/clues.js`，光束設定集中於 `src/logic/illumination.js`。

SpotLight 使用相同光束設定，一般光暖白、紫外光偏紫；不開陰影、不加後製。已接受一般光照可能穿過隔板的限制，隱藏字仍由 logic 嚴格做遮擋判斷。頂燈強度由 45 調到 26，環境光由 0.55 調到 0.45；是否保有足夠辨識度，由監督者確認。
