# 密室逃脫遊戲

第一人稱 3D 恐怖密室逃脫，場景是原創的「星星糖果樂園」。目前完成 STEP 0：固定相機的空房間與左上角 FPS 顯示，後續依 `PLANS.md` 加入玩法。

## 開啟遊戲（三位組員都適用）

使用支援 importmap、ES module 與 WebGL 的桌面版 Chrome、Edge 或 Firefox。遊戲是靜態網站，three.js 固定使用 `0.160.0`，由 jsDelivr CDN 載入，因此開啟時需要網路。**不用先執行 `npm install`，沒有 npm 套件依賴。**

請先確認電腦有 Python 3；以下指令使用電腦上的 Python，不會安裝任何專案套件。若指令找不到，先安裝 Python 3，再重新開啟終端機。

### Mac

1. 開啟「終端機」，輸入 `cd `（後面有一個空格），將專案資料夾拖進終端機，再按 Enter。
2. 確認所在資料夾看得到 `index.html`，執行：

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. 保持終端機開著，用瀏覽器前往 `http://127.0.0.1:8000/index.html`。

### Windows

1. 在檔案總管開啟專案資料夾，於網址列輸入 `powershell` 並按 Enter，終端機就會開在該資料夾。
2. 執行：

   ```powershell
   py -m http.server 8000 --bind 127.0.0.1
   ```

3. 保持終端機開著，用瀏覽器前往 `http://127.0.0.1:8000/index.html`。若只有 `python` 指令可用，可將上面的 `py` 換成 `python`，需為 Python 3。

兩種系統都按 `Ctrl+C` 停止本機伺服器。若 8000 埠已被使用，把指令和網址中的 `8000` 都改成 `8001`。

**直接點兩下 index.html 會打不開，原因是瀏覽器不讓本機檔案載入模組。** 請使用上述 `http://` 網址，避免使用 `file://`。本機伺服器只負責提供靜態檔案，沒有遊戲後端或帳號服務。

## 執行測試

安裝 Node.js 20 以上版本（包含 npm），在專案資料夾執行：

```sh
npm test
```

不需 `npm install`。這個指令使用 Node 內建的 `node --test`，執行全部測試。STEP 0 會確認 logic 在沒有瀏覽器的 Node 中能獨立載入，並遞迴掃描 `src/logic/` 的所有 `.js`，禁止匯入 three（包含 CDN、動態匯入與轉匯出）。

## 程式怎麼分

- `src/logic/`：純 JavaScript 遊戲規則；不使用 three.js、DOM、`window` 或 `document`，以一般物件和數值交換狀態。目前只有模組入口。
- `src/game/`：three.js 畫面，之後處理輸入與聲音，將 logic 狀態畫出來。
- `tests/`：Node 測試與 logic 邊界檢查。

## 畫面驗收與效能

開啟後應看到偏暗但可辨識的房間，有地板、四面牆、天花板與燈光；相機在房內。調整視窗大小時，畫面比例應跟著更新。可開啟瀏覽器開發者工具的 Console 確認沒有錯誤。目前尚無移動或碰撞功能。

左上角 FPS 約每秒更新一次。量測時保持分頁在前景，等待數秒再讀值。現在採簡單幾何形狀、像素比上限 1、無即時陰影與後製，降低內顯負擔。**30 fps 尚未在舊電腦驗證**；之後各批次結尾需在學校舊電腦全螢幕實測。
