## 玩家可見的變更

- 3142 貨運門：整片門板都能觸發原本門旁的密碼鎖。靠近兩公尺內、對準門板按 E／Xbox A／PS ✕，即可輸入原密碼。
- 追逐前第一道隔離門：整片門板都能觸發原本左側維修卡的讀取與記錄。內容及收集結果與讀取原卡相同；原有復位與開門條件延續。追逐開始後，身後的門不會因此重新開啟。
- 2413 的兩張文件：互動範圍直接由可見紙張的位置、朝向、寬高推導，四邊各留 8 公分容錯。準星對準文字或紙面即可記錄，不需瞄下面牆面。閱讀字幕仍保留。
- 操作指南會明示整片門可操作，文件則明示對準紙張記錄。

門面只是同一操作的額外互動表面。選取時僅略過對應的門片，其他牆壁仍阻擋，距離仍為兩公尺。紙張的薄判定避免自身擋住閱讀字幕；沒有把文字畫在最上層或讓玩家穿牆。

## Chrome 更新載入

先前出現內建瀏覽器可略過、Chrome 無法略過，與 Chrome 混用舊模組的情況相符；沒有宣稱已在 Chrome 重現並親測修復。啟動器現統一整個模組圖的內容版本，並使用禁止快取的本機伺服器。伺服器版本與資料夾都須一致才重用，避免啟動解壓新版卻仍玩舊副本。

固定使用 `http://127.0.0.1:8778/index.html`，網址加 `build` 查詢值可重新取得首頁，仍沿用相同瀏覽器與 origin 的存檔。HTTP 實測 71 份模組／樣式／圖片／引擎均與本機一致，附帶快取驗證也回傳目前內容；見 `browser-cache-check.json`。
