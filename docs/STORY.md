# 失落玩具工廠｜第一章劇情與線索設計

## 劇情主軸

玩家就是主角。多年後，主角收到匿名訊息，得知封廠前夜的夜班維修紀錄還留在工廠辦公室；訊息特別警告：「無論如何，別重啟主電源。」主角為查明工廠突然封閉的真相而進廠，入口隨即鎖死。原本的調查變成逃生。

本章回答兩件事：主角為什麼被困在工廠，以及復電後為什麼遭到玩偶追逐。故事仍保留三個後續謎團：玩偶為何在停電時離開展示台、匿名訊息是誰寄來、公司為何只用「設備故障」解釋封廠。

### 角色

- **主角／玩家：** 沒有預設姓名；因匿名訊息尋找夜班維修紀錄，進廠後必須找出路。
- **藍色展示玩偶：** 曾是公司的招牌迎賓玩具。封廠前夜後不再留在展示台，會巡邏、追逐和搜尋；失去玩家視線後會回到巡邏，不會全程黏著玩家。
- **匿名寄件者／夜班維修員：** 不直接登場。辦公室和控制室紀錄顯示，維修員發現監視畫面與門禁紀錄不一致，也警告過主電源會接通展示區備援線路。寄件者身分刻意保留。

### 玩家逐步查明的真相（劇情連貫線）

每區提供一項新證據，並讓下一步行動有明確理由；資訊不應一次全說破。

1. **辦公室：官方說法不可靠。** 公司公告稱「設備故障、全員安全撤離」，但匿名訊息要求找夜班維修紀錄。監視紀錄顯示停電後展示台已空，門禁卻沒有開啟紀錄。玩家此時仍以為可能是紀錄錯誤，目標是找員工卡與控制室資料。
2. **控制室：復電有風險。** 維修紀錄寫主電源曾被人手動切斷，備援線路接往展示區；有人留下「不要重啟」。玩家為打開離廠路線仍必須復電。復電後監視器畫面跳動、遠處傳來機械聲，首次把「怪物」可能存在從猜測變成迫近威脅。
3. **裝配線：異常不是單純停電。** 月台檢修碼 3142 和顏色復位提示讓玩家恢復貨運門；按錯警報後，監視畫面中的影子位置改變，證明廠內有東西在活動。R1 解開後主角自言自語：「這間工廠……怎麼感覺不是那麼簡單？難道真的有怪物嗎？不行，我得先離開這裡。等逃出去，再想辦法查清楚。」（約 10–15 秒；建議分兩句字幕，語氣由懷疑轉成警覺。）
4. **追逐走廊：危險已被證實。** 玩家親眼遭怪物追趕，維修卡證實有人預先留下出口密碼所需的代碼表；關門是為阻止怪物跟上，但同時把玩家困在前方路線。主角不再把追查真相放第一，需趕在怪物追上前找到出口控制廳。
5. **出口控制廳：公司曾安排撤離，但有人沒有離開。** 三條線索拼出 2413，解鎖的是員工緊急出口。控制面板的舊紀錄顯示這條路線曾被夜班維修員測試，卻沒有任何成功離廠紀錄；暗示匿名寄件者可能就是留下線索的人，但身份仍未知。玩家此時確認怪物存在，R2 解開後說：「它真的在追我……這不是故障，也不是我看錯。調查到這裡已經夠了，我必須立刻離開這座工廠！」（約 10–15 秒；若追逐狀態不允許完整語音，可用兩段短字幕呈現。）
6. **列車月台：只確認九成真相。** 控制室和監視資料足以拼出：公司宣稱設備故障、實際上有人手動斷電、復電會接通展示區備援線路、怪物在復電前已離開展示台；列車出口是被留下的最後撤離路線。仍未解釋怪物如何在無電時移動、它是否曾是玩具、匿名訊息由誰寄出、公司為何掩蓋真相。這些保留為後續懸念，玩家此刻優先逃生。

上述辦公室、控制室和監視資料的細節是劇情文字規格；若現行場景沒有對應可讀文件或畫面，應標為待新增場景文字，不宣稱玩家已實際看見。

## 開場短片／字幕｜約 60 秒，可跳過

開場需讓玩家在一分鐘內理解公司昔日受歡迎、封廠突然、官方說法可疑，並留下藍色玩偶異常的伏筆。五段各約 12 秒，字幕固定在畫面下方；可以跳過開場，不影響後續解謎資訊，因為必要線索會在場景重現。

1. **昔日盛況：**「這間玩具工廠曾是全城最受歡迎的玩具公司。藍色迎賓玩偶是招牌，廣告總說：『最好的朋友，陪你直到回家。』」畫面先呈現正常營業與玩具宣傳。
2. **突然封廠：**「後來某一夜，工廠突然停產。公司只公告『設備故障』，沒有事故說明，員工也再沒回來。」畫面切到停產封條與熄燈廠房。
3. **異常影像：**「封廠前最後一段影像裡，展示台上的藍色玩偶突然抽動了一下……接著畫面中斷。沒有人知道那是故障，還是它真的動了。」只閃現原創剪影，不展示變異原因或血腥畫面。
4. **匿名訊息：**「多年後，你收到一則匿名訊息：『真正的夜班維修紀錄還在辦公室。無論如何，別重啟主電源。』」
5. **進廠與被困：**「你依訊息進入廢棄工廠。大門在身後鎖死，遠處閃過一道藍影。手電筒、地圖和員工卡就在辦公室；你必須找到出口，也查明那一夜發生了什麼。」

以上是開場劇本文字和分鏡提案。現行頁面有約 60 秒的五段文字及跳過按鈕；若沒有影像素材，不要在文件或交付說明中稱它為已完成影片。字幕位置、時長及跳過功能以實際遊戲驗收為準。

## 解謎流程與密碼推導

### 目前已有的密碼

- **控制室 4726：** 玩家用紫外光照出牆上的檢修碼，安裝保險絲後輸入，恢復主電力。
- **裝配線 3142：** 玩家在控制器附近看到月台檢修碼，解鎖貨運門。

### R1 顏色序列謎題：場景提示到答案的推導

玩家可在裝配線控制器旁的牆面找到「校正說明：依紅、黃、綠、藍燈號逐一復位」；四顆實體按鈕須有大面積、高對比的紅、黃、綠、藍色面，並各自印上顏色名稱或色塊圖示，不能只靠細小燈點辨色。玩家依提示逐一按下同色按鈕即可解題，無需猜測或依賴外部說明。控制器下方應有固定文字：「請依燈號提示輸入復位順序。」按對前三顆時進度前進，按完第四顆解鎖貨運門並保留復位燈序線索。任一步按錯會清空本輪全部進度，四顆按鈕短暫轉為警告紅色，播放一聲短促錯誤提示音，並顯示「密碼輸入錯誤，請重新輸入。」之後按鈕恢復原本顏色，玩家可從第一顆重新輸入；不需重開遊戲。解題後再按按鈕不得把謎題重置。

可理解性驗收：首次遊玩的測試者不得先聽到口頭答案；只看場景告示、按鈕和提示文字，應能說出順序並完成。若告示被遮、顏色難辨、輸錯後未清空，或提示音／錯誤文字不清楚，應判此項未通過。此處的 UI 顏色回饋、音效和訊息需主程式接線，屬實作工作；Ryan 提供規則與文案。

### R2 出口密碼：2413

三條線索分別放在裝配線、追逐走廊和出口控制板，玩家不能只靠猜測：

1. **裝配線（`production.color-clue`）：** 復位燈序為紅、黃、綠、藍。它必須和 R1 謎題的正式答案一致。
2. **追逐走廊（`corridor.color-key`）：** 維修卡給出代碼對照：紅＝3、黃＝1、綠＝4、藍＝2。
3. **出口控制板（`exit.reverse-clue`）：** 指示「將復位燈序反向輸入」。

因此輸入順序是 **藍 → 綠 → 黃 → 紅**，代入對照後得到 **2 → 4 → 1 → 3**，出口碼為 **2413**。`deriveExitCode()` 從三筆線索資料計算密碼，`exit.final` 直接引用這個結果。三條線索各自顯示在裝配線告示、走廊維修卡和出口控制板；遊戲要求收齊三條才接受答案。整合版已接入正式路線。

### R2 延伸提案：列車啟動密碼（尚待設計接入）

玩家通過出口密碼 2413 後，仍須解開列車啟動碼才能啟車。這道題不是照顏色順序按按鈕，而是閱讀三份分散的機械讀數、套用公式並排序，和 R1 的解法不同。

- **月台控制台文字：**「緊急啟動碼：讀取牽引、制動、照明三項維修值，各除以 6；將結果由小到大排列。最後在三位數前加上月台軌道數。」
- **三張可互動維修卡：** 靠牽引馬達的卡寫「牽引 18」；制動閥旁寫「制動 12」；頭燈電箱旁寫「照明 6」。標籤和讀數必須同框可見，並能與控制台的三個項目對應。
- **玩家推導：** 18÷6＝3、12÷6＝2、6÷6＝1；由小到大排列得 123。月台上可見兩條平行軌道，所以軌道數為 2；把 2 放在三位數前面，得到四位碼 **2123**。
- **可選提示（逐級揭露，不直接代答）：** 提示一「控制台提到三個系統，找到同名的三張卡。」提示二「每個讀數先除以 6，再把結果由小到大排。」提示三「三個結果是 3、2、1；先排成 123，最後再看軌道數。」提示只在玩家主動要求時顯示；正式遊戲若沒有提示 UI，至少要把公式完整寫在控制台旁。
- **輸入規則：** 控制台下方文字為「請輸入列車啟動碼」。輸錯清空整個輸入、顯示「密碼輸入錯誤，請重新輸入。」並允許立刻從頭再試；不重置已收集線索或其他關卡進度。正確輸入後明確顯示「列車已啟動」，再觸發列車演出。

此題目前是 Ryan 提出的劇情／謎題規格，牽引、制動、照明卡片及控制台公式尚未放進遊戲，需 Eric 接線後才可算完成。驗收時不告訴玩家答案；若玩家看不懂何謂「前面加上軌道數」，即表示提示仍不足，應把控制台文字改成「將軌道數放在三位數最前面」，而不是判玩家失敗。

尾聲追逐中，怪物會持續從後方逼近；設計目標是造成壓迫感而非時間陷阱。玩家應能停下閱讀三張卡、計算、輸入並有合理重試機會。怪物速度、抓捕條件、線索位置與安全操作時間由 Eric 接入和平衡；Ryan 的驗收條件是首次遊玩的測試者只靠場景線索可推得 2123，並能在怪物壓力下完成或重試，不需口頭提示。建議第一次完整遊玩時記下從看見控制台到輸入正確碼的實際時間；由 Eric 依該時間設計追逐速度與距離，不預先捏造一個看似精確但未實測的怪物速度。

## 結局與首尾伏筆

目前已整合結局：列車啟動後，玩家登車逃離；控制室紀錄說明復電接通展示區備援線路，卻無法解釋監視器早在停電期間已拍到玩偶離開展示台。開場廣告「最好的朋友，陪你直到回家」在尾端車廂再次響起，車門從內側扣上，留下玩偶是否跟上列車的懸念。

#### Ryan 希望新增的尾聲分鏡（劇情稿，尚待主程式接入）

此提案要把「解鎖出口／登車即勝利」改成最後一段逃生挑戰。以下全段在列車控制台成功啟動後播放；演出期間玩家不能移動、操作、暫停跳過或略過劇情，鏡頭固定朝向車頭與前方軌道。實際不可跳過政策仍須由 Eric 在程式中實作。

1. **列車啟動：** 控制台密碼正確，燈號由紅轉綠，車頭燈亮起，警報聲被引遠。玩家角色低聲：「快走……拜託快走。」列車緩慢離開月台。
2. **怪物攔車：** 車廂開始加速後，藍色玩偶突然從黑暗側道衝到車頭前方。它張開雙臂擋路，車頭燈照亮它的剪影；不呈現血液、肢體破損或寫實撞擊特寫。
3. **撞擊與通過：** 撞擊以燈光震動、金屬聲和車身顛簸表現。怪物被撞倒並留在軌道後方，列車未停下。用剪影和音效表達，不出現血腥畫面。是否確定怪物死亡不明說，避免和後續伏筆衝突。
4. **隧道與角色台詞：** 列車駛入隧道，照明逐漸收窄，只照見車頭、近處鐵軌和一小段隧道牆。演出持續約 15–25 秒，玩家不可控制也不可跳過。主角可分段說：「這恐怖的工廠……終於要逃出去了嗎？」稍停後：「不對……我還不能放鬆。只要離開這裡……」台詞應保留不確定感，不能提前宣布安全。
5. **失靈脫軌：** 列車燈閃一次後熄滅，動力聲逐漸下降，接著猛烈偏移並撞上隧道側壁。用一次強烈聲響與短暫鏡頭震動，不加血腥或傷害特寫。畫面完全黑下後顯示「遊戲結束｜END」。

這段是 Ryan 提供的劇情與演出規格，不代表現行程式已具備列車密碼、怪物列車攔截、定時台詞或脫軌事件。怪物速度必須讓玩家在追逐壓力下仍有可完成的思考與輸入時間，屬於主程式遊戲平衡工作；不能只靠文件宣稱已平衡。建議整合者至少以完整路線實測密碼解題、錯誤重試、被追時的可達性及演出觸發一次，並記錄結果。

## 可實玩的驗收步驟

1. 依 README 用本機 HTTP 伺服器啟動遊戲，不要用 file://。開始遊戲後看完 60 秒開場或按「跳過劇情」；記下廣告標語「最好的朋友，陪你直到回家」。
2. 在辦公室用準星瞄準並按 E（手把 A／✕）拿手電筒、地圖、員工卡；確認公告說設備故障，備援紀錄卻說停電後玩偶離開展示台。
3. 用員工卡開控制室門。撿保險絲、裝入電箱，按 F 開燈、按 R 切 UV 照檢修碼，輸入 4726；確認復電打開裝配線門，劇情提示說明備援線路也接通。
4. 進裝配線找到月台檢修碼 3142，輸入後打開貨運門。避開玩偶視線，利用機台或置物櫃躲藏。
5. 在裝配線告示讀出紅→黃→綠→藍，依序按下同色按鈕；再刻意按錯一次，確認進度重置、警報響起且仍可重試。這項場景提示可理解性要由首次遊玩的測試者獨立操作確認，不能先口頭告訴答案。
6. 通過追逐走廊並取得維修卡；核對紅＝3、黃＝1、綠＝4、藍＝2 可讀，隔離門通過後關閉，怪物追逐期間仍有路線可走。
7. 收齊裝配線、走廊、出口控制板三條線索，按紅黃綠藍反向得藍綠黃紅，再換成 2413。確認少任一線索時不能開門、錯碼可重試、正確碼開門。
8. **現行版本驗收：** 刷員工卡啟動列車、登車，確認目前結局和完整地圖獎勵；鍵鼠與手把菜單依 README 驗收。
9. **未實作提案驗收：** 若列車密碼與新演出完成，先不給測試者提示，確認能從線索推得密碼；啟動後確認全程鎖定操作且不可跳過、怪物突然攔車、撞擊無血腥特寫、隧道演出約 15–25 秒、主角台詞出現、列車失靈脫軌、全黑後顯示 END。追逐壓力下應可完成謎題；若時間不足或路徑無法通過，記錄為平衡缺陷，不要標成通過。
10. 每次實玩記錄版本／commit、日期、操作者、電腦／OS／瀏覽器／手把、案例、預期與實際結果及證據；未實測項目保持待驗。
