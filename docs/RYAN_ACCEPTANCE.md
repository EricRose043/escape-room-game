# RyanDing1010｜劇情與謎題驗收流程

本文件只記錄 Ryan 負責的劇情、謎題提示、結局文案和素材來源驗收。它是給第一次遊玩的測試者使用的操作稿，不取代 shuoen88 維護的 `TESTS.md`、`docs/TESTING_LOG.md` 或 `docs/DEFECTS.md`。沒有實際跑過的項目保持「待實作／待實測」，不可填成通過。

## A. 現行版本：已整合內容

### A1 開場與辦公室

1. 以 README 指定的 HTTP 方式啟動，不用 `file://`。重新開始遊戲，觀看約 60 秒的五段開場，另測一次按「跳過劇情」。
2. 確認字幕固定在畫面下方、可讀且跳過後可開始遊戲；開場有昔日盛況、突然封廠、藍色玩偶影像異常、匿名警告和入廠被困。
3. 在辦公室讀取「設備故障停工；展示區列為事故現場」與「停電後玩偶離開展示台」兩項紀錄。確認兩句互相矛盾，能引起調查動機。
4. 取得地圖、手電筒與員工卡。檢查地圖確實標出控制室／裝配線／貨運月台，且員工卡提示能開控制室。

### A2 控制室與揭露

1. 以員工卡進控制室，取得保險絲並安裝；照 UV 提示讀出 4726，恢復主電力。
2. 讀取「封廠前夜 22:14｜備援監視器拍到玩偶離台，門禁沒有開啟紀錄」及「主電源重啟會接通展示區備援線路」。
3. 確認玩家能理解復電是通往出口的必要選擇，但會帶來風險。記下玩家是否能用場景文字推知這點，而非由測試者口頭解釋。

### A3 R1 顏色謎題首次遊玩測試

1. 進裝配線，先不向玩家透露顏色答案。請玩家自行找到月台檢修碼 3142 並打開檢修控制器。
2. 讓玩家閱讀牆面校正告示「依紅、黃、綠、藍燈號逐一復位」，再自行說出要按的顏色順序。
3. 確認紅、黃、綠、藍按鈕顏色面積夠大、彼此容易區分；顏色名稱／圖示同時可辨，不能只靠小燈或色覺判斷。確認下方有「請依燈號提示輸入復位順序」。
4. 玩家按紅、黃、綠、藍，確認正確序列解開並開啟貨運門。
5. 重新開始遊戲或依可用重置方法回到未解謎題；先按一個正確按鈕再按錯色。確認：本輪進度清零；四鈕短暫顯示警告紅色；播放一次短促錯誤音；出現「密碼輸入錯誤，請重新輸入。」；按鈕之後恢復辨識色；玩家能從第一顆重試，不必重開整場。
6. 完成後再按按鈕，確認已解狀態不會倒退。若玩家第一次不能僅依場景提示解出，記錄他看漏的文字、按鈕可見性、色彩辨認或訊息理解，不要把口頭告知後成功算通過。

## B. 現行版本：R2 三線索出口密碼 2413

1. 在裝配線讀取復位燈序紅、黃、綠、藍；記下這是第一條線索。
2. 通過追逐走廊時讀取維修卡：紅＝3、黃＝1、綠＝4、藍＝2；記下這是第二條線索。
3. 在出口控制板讀取「將復位燈序反向輸入」；記下這是第三條線索。
4. 讓玩家先自己推導：紅黃綠藍反向為藍綠黃紅；依照維修卡代換成 2、4、1、3，得到 2413。
5. 確認收齊三條線索才可輸入；少任一條時即使玩家輸入 2413 也不得開門。錯碼可重試；正確碼解鎖出口。
6. 記錄玩家在哪一條線索卡住。若線索文字本身已有答案但不明白「反向」或對照關係，將原話記錄下來供 Ryan 修文案；不要替他補講答案。

## C. 列車新增謎題：提案，未接入前不得判通過

**題目答案：2123。** 月台控制台明示三項系統讀數各除以 6，結果由小到大排列，再把月台軌道數放在三位數前面。三張卡分別是牽引 18、制動 12、照明 6。玩家算出 3、2、1，排序為 123；現場可見兩條軌道，前置 2，得到 2123。

1. 玩家進入月台後先檢查列車控制台指示，再自行尋找牽引、制動、照明三張卡；卡片標題及數值需完整可讀。
2. 不提供口頭提示，記錄玩家是否理解除以 6、由小到大排列、把軌道數置前這三步。若卡住，只允許使用控制台旁的逐級提示：先指出三項系統、再提醒除以 6 並排序、最後提醒軌道數在前。
3. 玩家輸入錯誤時確認整組輸入清空，顯示錯誤文字並可立即重試；不丟失已收集線索，也不要求重開遊戲。正確碼 2123 啟動列車。
4. 此題與 R1 顏色序列的操作方式不同，仍須先由 Ryan 確認採用，Eric 放入線索與控制台後再進行實玩驗收。

## D. 新列車演出：提案，未接入前不得判通過

列車啟動後整段固定鏡頭、玩家不可操作、不可暫停跳過；約 15–25 秒隧道段落。驗收順序：列車離開月台 → 怪物突衝到車頭前 → 用剪影、撞擊聲和車身震動呈現非血腥撞倒 → 列車進入逐漸變暗的隧道，畫面只保留車頭燈及近處隧道 → 主角台詞 → 動力失靈與脫軌撞壁 → 全黑 → 顯示「遊戲結束｜END」。

1. 確認演出只有在列車密碼正確、列車啟動後觸發一次；輸入錯誤不得偷跑劇情。
2. 確認整段無移動、互動或跳過輸入能改變鏡頭／劇情狀態；演出中斷、失焦或重新載入的處理需由整合者另訂，不可由驗收者假定。
3. 確認怪物突然出現但不以血液、肢體破損或撞擊特寫呈現；怪物是否死亡保留未知。
4. 確認主角在撞擊後才說「這恐怖的工廠……終於要逃出去了嗎？」再說「不對……我還不能放鬆。只要離開這裡……」。列車失靈前不得先顯示安全逃脫或勝利。
5. 確認隧道變暗仍可辨認車頭及前方短距離；脫軌時一次明確撞擊，隨後全黑和 END 字樣。沒有血腥效果。
6. 另做追逐解謎可行性測試：第一次玩家需能看卡、計算、輸入並至少有一次合理重試機會。記錄解題耗時、怪物距離／抓捕結果與操作失敗原因；速度和 AI 由 Eric 調整，不能把「來不及解」歸咎玩家。
