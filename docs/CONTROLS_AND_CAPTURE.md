# 2026-11-04 手把配置與抓捕規則調整

使用者要求指引依實際手把布局呈現，並明確選擇「一旦被看見就觸發必定抓到的驚嚇演出」。本輪仍是本機交付，沒有宣稱新程式已推送到GitHub。

## 操作指引

- 主選單與暫停操作指南使用完整手把圖；Xbox左上搖桿、左下十字鍵，PlayStation下方對稱雙搖桿。
- 遊戲內提示使用圓形搖桿、十字鍵、肩鍵和對應面鍵圖示。鍵盤裝置才使用鍵帽；不把「左搖桿／右搖桿」放在鍵盤方塊內。
- 圖上保留實際面鍵位置：上Y／△、下A／✕、左X／□、右B／○。左肩LB／L1切換光線，右肩RB／R1開關手電筒。
- PS地圖鍵標Create／Share，暫停為Options。Xbox對應View與Start。未綁定的扳機、左側面鍵與搖桿按壓沒有捏造功能。
- 指引隨最後使用的裝置切換；無法識別品牌的標準映射手把註明名稱可能不同。
- 鍵盤密碼鎖說明已修正為數字鍵輸入／滑鼠點按，手把用十字鍵選格。

控制圖以原創SVG向量繪製，沒有外部圖片或字型依賴。Xbox與PS圖已使用本機Sharp／librsvg渲染成PNG檢查位置、引線與文字；這項檢查不代表已在受限制的瀏覽器驗收完整頁面。

## 發現即抓捕

- 裝配線娃娃真正看見玩家時立即觸發抓捕，先於同幀移動、進櫃與開面板判定；已被發現後不能甩掉或取消。未被發現前仍能提前躲藏。
- 演出2.1秒：先黑場，0.15–1.45秒近景，再黑場回最近的合法存檔點。失焦與暫停安全凍結；驚嚇近景關閉時仍只有黑畫面，不改已儲存的使用者偏好。
- 近景由八個獨立Canvas圖層構成：75ms突進、異高眼睛、彎齒裂口、下顎及雙手收攏。不是整張圖緩慢放大，沒有閃爍。
- 必經追逐走廊仍依原跑動路線運作。新增正式潛行路線測試，從已合法解鎖的裝配線存檔點，靠真實移動、遮擋、操作，走完後續機關、2123、登車及脫軌END；途中沒有傳送或補造後段進度。
- 原monster純模組的搜尋／追蹤測試保留；章節層把實際可見事件轉成必定抓捕。舊整合測試中不再成立的逃脫期望與1.2秒時間已依新需求遷移。

## 告示與軌道實玩回饋

使用者截圖證實公式被橫桿與管線遮擋，原中心射線檢查沒有涵蓋斜看角度；另指出現場一組軌道不能被合理理解為兩組。這是本次需修正的實際問題，沒有把它歸因玩家理解。

- 長公式改成五步分段，文件安裝位置保留整塊淨空，移開穿越文字的裝飾與前方吊索；不靠關閉深度測試讓文字穿過模型。
- 現場增加兩組完整軌道，各有兩根鋼軌、枕木、道床與地面01／02編號。題目明確數完整軌道組數，答案仍為2123，不改已完成玩家的解題進度。

## 最後驗證

最後完整測試265/265通過，包含真實潛行路線到2123與脫軌END。全場景1,200次更新無資源成長；18份文件的1,350條可達閱讀射線零遮擋，另排除並記錄108條穿過實牆的不可達視線。公式本身81次全通過，檢查包含三種距離、左右偏移、中心／四角／四邊。結果見document-readability-check.json。72份實際HTTP相依資源與本機來源逐位元相符。

控制圖已看過原創SVG的PNG渲染，近景已看過真Canvas繪圖與CPU透視預覽；這些不冒充瀏覽器截圖。實際瀏覽器、GPU合成與實體手把仍需要具備設備的操作者試玩。

## 黑畫面實玩問題修正

使用者隨後回報只有黑畫面。檢查確認：舊遊戲入口與已儲存的jumpScare=false仍把所有動畫圖層關閉；不是已驗證畫面正確。獨立使用實際HTML、CSS、jsdom與真Canvas檢查127幀，設定開啟時78幀內八層有色且可見，關閉時精確重現純黑。證據見capture-dom-check.json；此項仍不是瀏覽器GPU驗證。

依使用者最新要求，遊戲與設定入口現在共用createGameSettingsStorage：預設開啟，新版首次只把舊驚嚇設定同步為true，保存一次升級標記，不改音量、靈敏度與遊戲進度；之後手動關閉仍會跨重載保留。URL明確jumpscare=0或1會同步啟動值與設定面板，不再有面板關閉但主程式獨立開啟的雙重來源。本項取代上方先前「不改舊驚嚇關閉值」的交付策略。

新增實際main整合回歸：舊false載入新版後true，抓捕時canvas確實解除隱藏，手動關閉後下一次載入仍false。另有首次遷移／保留其他設定／兩入口一致／URL／儲存失敗回歸；完整270/270測試通過。
